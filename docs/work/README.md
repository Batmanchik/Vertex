# Текст научной работы: исходники

> **Что это:** источник текущего текста работы. Карта документов —
> [../../DOCS.md](../../DOCS.md).

Три файла собираются скриптом в один docx:

```
python scripts/make_scientific_work.py
```

| файл | что внутри |
|---|---|
| `part1_intro.md` | титул, абстракт на трёх языках, оглавление, введение, раздел 1 |
| `part2_method.md` | разделы 2 и 3: типологии, ER, `W`, OES, ансамбль, методология, результаты, ограничения, пять дефектов |
| `part3_conclusion.md` | заключение, список источников, дневник |

Результат — `artifacts/Vertex_scientific_work.docx`. **Правится исходник, а не
docx**: следующая сборка затрёт ручные правки в Word.

## Разметка

Каждая строка начинается с тега и вертикальной черты. Скрипт падает на
неизвестном теге, поэтому комментариев в этих файлах быть не может — все
пояснения живут здесь.

| тег | что делает |
|---|---|
| `TITLE\|`, `TITLE2\|`, `CENTER\|`, `GAP\|` | титульный лист |
| `H1\|`, `H2\|` | заголовки разделов и подразделов |
| `P\|` | абзац, `**жирный**` внутри поддерживается |
| `LIST\|` | элемент списка |
| `FORMULA\|` | формула отдельной строкой |
| `TABLE_*\|` | вставка таблицы, собранной в самом скрипте из измерений |
| `FIGURE\|` | путь и подпись через `;` |
| `TOC\|`, `PAGEBREAK\|` | оглавление и разрыв страницы |

Таблицы живут в `scripts/make_scientific_work.py`, а не здесь: числа в них те
же, что в `docs/RESULTS.md` и `artifacts/*.json`.
